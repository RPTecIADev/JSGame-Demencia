## 📌 Sobre o Projeto

O **JSGame-Demencia** é um jogo interativo desenvolvido para a web (HTML, CSS e JavaScript Vanilla). Este projeto foi construído com o intuito de demonstrar forte domínio em lógica de programação, manipulação da DOM, gerenciamento de estado e animações, oferecendo uma experiência de usuário (UX) engajadora.

*(Nota: Adicione aqui detalhes específicos sobre o tema de Demencia. É um jogo de memória? Um jogo de ação? Detalhe a mecânica principal do seu jogo aqui).*

## 🎯 Por que este projeto se destaca? (Visão para Recrutadores)

Para quem está avaliando o código, este projeto evidencia habilidades fundamentais de front-end:
* **Código Limpo e Modular:** Construído com boas práticas de desenvolvimento e separação clara de responsabilidades.
* **JavaScript Vanilla:** Foco na base da linguagem sem dependência inicial de frameworks externos, evidenciando conhecimento em ES6+.
* **Design Responsivo e UI/UX:** Interface projetada para ser adaptável e responsiva, com feedback visual imediato.
* **Resolução de Problemas Algorítmicos:** Implementação de regras de negócio de um jogo (pontuações, colisões, temporizadores, ou fluxo de estados) que exigem forte raciocínio lógico.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Semântica e estruturação dos elementos na tela.
* **CSS3:** Estilização avançada, layout com Flexbox/Grid e animações nativas.
* **JavaScript:** Motor lógico do jogo, eventos de interface e controle de áudio/vídeo.

## ⚙️ Como Funciona a Estrutura e Lógica

O projeto está organizado da seguinte forma para facilitar a escalabilidade:

```text
📦 JSGame-Demencia
 ┣ 📂 assets
 ┃ ┣ 📂 css        # Estilização modular da interface
 ┃ ┣ 📂 js         # Lógica principal, dividida em controladores
 ┃ ┣ 📂 images     # Sprites, backgrounds e assets visuais
 ┃ ┗ 📂 audio      # Efeitos sonoros para imersão
 ┣ 📜 index.html   # Estrutura principal da aplicação
 ┗ 📜 README.md    # Documentação
```

### Mecânicas Implementadas
1. **Loop / Estado do Jogo:** Controle do ciclo de vida da partida desde a tela inicial até as condições de Game Over ou Vitória.
2. **Gerenciador de Interações:** Captura de eventos do usuário (clique, teclado) processados em tempo real.
3. **Manipulação Dinâmica:** Elementos visuais são criados, modificados e destruídos na DOM em tempo real utilizando JavaScript.

## 🚀 Como Rodar o Projeto Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/RPTecIADev/JSGame-Demencia.git
   ```
2. Acesse o diretório:
   ```bash
   cd JSGame-Demencia
   ```
3. Abra o arquivo `index.html` em seu navegador, ou inicie um servidor local (ex: extensão *Live Server* no VS Code).
